Jewelry Oblako

A private file-sync tool for one small business.

What it does

Jewelry Oblako keeps one working folder identical on the owner's two computers. It copies changed files through the owner's own Google Drive: what was edited on one computer appears on the other. It is used only by its owner and is not offered to the public.

It uses the Google Drive API with the drive.file scope, so it can see only the files it created itself — not the rest of the Google Drive.

Что это

Jewelry Oblako — программа обмена рабочей папкой между двумя компьютерами владельца через его собственный Google Диск. Видит только файлы, которые создала сама. Используется только владельцем.
